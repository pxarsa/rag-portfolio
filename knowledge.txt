Python is a popular programming language used for automation, web development, and data analysis.

Machine learning is a branch of artificial intelligence that allows computers to learn patterns from data.

Embeddings represent text as numerical vectors. Similar meanings can have similar vector representations.

RAG stands for Retrieval-Augmented Generation. It retrieves relevant information from external sources and uses that information to help a language model generate answers.

Chunking is the process of splitting a long document into smaller pieces. It helps a retrieval system find relevant information more precisely.

Git is a version control system that tracks changes in files and helps developers manage their code.
